# RecordKit user-documentation source

This directory is the hand-written source for RecordKit's user-facing documentation and GitHub Pages site. Begin at [index.md](index.md).

Public documentation is organised by the user's goal rather than the source-code structure. Cross-link related concepts so readers do not need to traverse the hierarchy linearly.

Explanatory user documentation is reviewed and written by people. Automated tooling may build the site and check links, but it must not generate the explanatory content from code.
