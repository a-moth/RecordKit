# RecordKit documentation

RecordKit is a local-first journal for structured data that you define yourself. Create reusable templates, then make entries from those templates whenever you want to record something.

## Choose where to begin

- [Getting Started](getting-started/): understand templates and entries and create your first record.
- [Use Cases](use-cases/): see how the configurable model can support different kinds of personal data.
- [Concepts & Features](concepts-and-features/): learn how templates, entries, fields, sections, settings, and validation work.
- [Data & Programmatic Use](data-and-programmatic-use/): understand local storage, portability, import/export direction, and planned programmatic access.
- [Planned Functionality](planned-functionality/): see what is planned and how confidently it can be described.
- [Limitations](limitations/): review current product and accessibility boundaries.

RecordKit keeps core data on your device. It does not automatically sync or send your records to a RecordKit service.
