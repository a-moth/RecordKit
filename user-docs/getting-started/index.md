# Getting Started

RecordKit works through two central ideas:

- A **template** describes the information you want to collect.
- An **entry** is one completed record made from that template.

For example, a symptom template might ask for a date, pain scale, activities, and notes. Each time you complete it, RecordKit creates a new entry while leaving the template available for future use.

RecordKit 1.0 provides template and entry creation, editing, deletion, typed fields, nested sections, ordering, settings, and validation. Detailed task-by-task instructions and reference images will be added as the interface stabilises.

> **Limitation:** RecordKit does not currently provide automatic device sync or a hosted account service. Core data remains on the device where it was created.
