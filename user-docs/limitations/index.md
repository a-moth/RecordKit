# Limitations

**The items below describe current product boundaries that may materially affect whether RecordKit fits a user's needs.**

## Storage and devices

RecordKit stores core data locally and does not currently provide automatic device sync or a hosted account service. Moving data between devices is not yet a complete user-facing workflow.

## Images

Image-boolean fields currently use bundled images. Durable user-uploaded image handling is planned after the storage migration.

## Analytics and programmatic access

Analytics and the local API are planned future features. RecordKit 1.0 is focused on collecting and managing records rather than analysing them automatically or exposing them through an API.

## First-run guidance

The dedicated welcome and first-run experience is planned for version 1.4.

## Accessibility

Accessibility is an active cross-cutting requirement, but the project has not yet completed and published a comprehensive accessibility conformance audit. Feature-specific barriers should be reported through the accessibility issue form.

On ordinary documentation pages, a **bold red-styled limitation callout** identifies unsupported or bounded behaviour, while a *yellow-styled warning* identifies usable behaviour that requires caution. This page uses normal section formatting so the limitation list remains readable.
