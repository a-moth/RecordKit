# Data & Programmatic Use

RecordKit is local-first. Core application data is stored on the device, and RecordKit has no hosted server that receives records automatically.

The project intends exported data to remain usable by other software. Full import/export instructions and a stable public data reference will be documented as those interfaces are implemented.

Third-party health or general API integrations are future functionality. Any such integration must be explicitly configured by the user; it will not be enabled by default.

> **Limitation:** RecordKit 1.0 does not provide the planned local API, automatic device sync, or a complete public import/export workflow.
{: .limitation}

The local-host-only API is planned for version 3.0. See [Planned Functionality](../planned-functionality/) for the current roadmap summary.
