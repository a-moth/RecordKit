# Testing documentation

RecordKit 1.1 is establishing comprehensive white-box coverage for the released product. Start with the [testing overview](overview.md), then use the guide for the subsystem being changed:

- [Data model](data-model.md)
- [Fields and registry](fields.md)
- [Validation](validation.md)
- [Storage](storage.md)
- [Settings](settings.md)
- [Components and screens](components.md)

These pages define testing responsibilities and representative cases. They are not claims that every listed case is already covered. The current coverage state is determined by the tests in the repository and the active [1.1 plan](../../PLANNING-1.1.md).
