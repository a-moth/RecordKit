# RecordKit 1.4 — Welcome and first-run experience

## Status

Planned after 1.3.

## Objective

Create a low-cognitive-load welcome experience that introduces RecordKit's configurable model and gets a new user to their first useful record.

## Current state

`app/welcome.tsx` is TODO-only and has no component or default export.

## Scope

- Define the first-run route and completion state.
- Explain templates and entries without requiring technical terminology.
- Provide a clear route into creating or selecting a first template.
- Respect accessibility requirements for focus, screen readers, contrast, touch targets, and reduced motion.
- Add white-box coverage for first-run state and navigation.

Detailed copy and interaction decisions should be made close to implementation and reflected in `user-docs/` after behaviour stabilises.
